# WeMeet

WeMeet is a video call platform for connecting with friends and family, as well as hosting official meetings. The goal is to make it easy to meet face-to-face online, whether for a casual catch-up or a professional conversation.

## Technology stack

- **React.js** for the user interface
- **Vite** for frontend development and builds
- **Tailwind CSS** for styling
- **Node.js** and **Express.js** for the backend
